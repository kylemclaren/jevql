Standard library only: `urllib` for HTTP and `subprocess` for the CLI. Install the binary first ([Install](/docs/install/)).

## HTTP transport

```python
from jevql import Jevql, JevqlError

db = Jevql(url="http://127.0.0.1:7433", token="secret")

res = db.query(
    "SELECT name, jev_prob(people, 'could work from home') AS p FROM people WHERE country = 'PT' ORDER BY p DESC LIMIT 5",
    threshold=0.6,
)
res.columns        # ["name", "p"]
res.rows           # [["Miguel Costa", 0.94], ...]
res.stats.usd      # 0.00005

for row in db.query_dicts("SELECT * FROM tickets WHERE jev(tickets, 'is about billing')"):
    print(row["subject"])

plan = db.explain("SELECT * FROM people WHERE jev(people, 'x')")
```

Start the server with `jevql serve --listen 127.0.0.1:7433 --token secret`.

## CLI transport

```python
db = Jevql.cli(binary="jevql", database_url=os.environ["DATABASE_URL"], api_key=os.environ["TYPESAFE_API_KEY"])
rows = db.query_dicts("SELECT 1 AS one")
```

## Errors

```python
try:
    db.query("SELECT * FROM nope")
except JevqlError as e:
    print(e.code, e.status, e)   # "sql", 400, 'relation "nope" does not exist'
```

`code` is one of `sql`, `budget`, `api`, `auth`, `internal`, `transport`.

## Types

`QueryResult`, `Stats` and `Explain` are dataclasses with `from_dict`. `QueryResult.dicts()` zips columns and rows. `Jevql` works as a context manager.
